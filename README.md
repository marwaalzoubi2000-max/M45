# مصعب • رياضيات — Android

تطبيق أندرويد مستقل على M45، لتشغيل أوزان MUSAB V12.2 محليًا. لا يعدّل تدريب Kaggle ولا يستأنفه ولا يتصل بخادم. المستودع لا يحتوي أوزانًا أو بيانات خاصة.

## الواجهة

تحميل الأوزان، كتابة المسألة، حل/إيقاف، مسح السؤال والجواب، عرض جواب النموذج، وإعادة تعيين مع تأكيد. الأوزان المستوردة تبقى في مساحة التطبيق الخاصة بعد إغلاقه. اختيار ملف غير متوافق لا يستبدل النموذج السابق. اللغة العربية للواجهة؛ يُفضّل سؤال إنجليزي لأن تدريب النموذج إنجليزي.

## الحصول على APK

من تبويب Actions افتح أحدث تشغيل ناجح لـ **Build Android APK**، ثم نزّل **MusabMath-debug-APK** من Artifacts، وفك الضغط وثبّت APK. هذه نسخة اختبار، وليست حزمة نشر على Google Play. Android 8+ ومعالج arm64 أو x86_64. لا نطلب صلاحية الإنترنت أو الوصول الشامل للتخزين.

## ربط أوزانك

ملفات PyTorch `.pt` ليست ONNX ولا يمكن إعادة تسمية امتدادها لتعمل. استخدم **نسخة من `laptop_fp16.pt`** الموجودة في مخرجات جلسة التدريب. يكفي أفضل تصدير متاح حتى قبل اكتمال التدريب؛ جودة الأجوبة هي جودة تلك الأوزان.

نفّذ في بيئة Python منفصلة (يمكن نوتبوك تحويل مستقل على Kaggle):

```bash
pip install -r tools/requirements.txt
python tools/export_android.py --weights /path/to/laptop_fp16.pt --output musab_android.onnx
```

يجب أن يظهر `EXPORT_VERIFIED`؛ الأداة تقارن logits في 4 أطوال وقرارات توليد متتابعة قبل إخراج الملف. بعدها انقل `musab_android.onnx` إلى الهاتف واضغط **تحميل الأوزان** واختره. لا ترفع أوزانك إلى هذا المستودع العام. لا يلزم `resume.pt` أو `index` للتطبيق. لا تغيّر نوتبوك التدريب أو ملفاته.

## حدود النسخة

- الأوزان FP16 تُحوّل إلى FP32 للتوافق مع CPU؛ ملف ONNX قد يكون أكبر من ملف اللابتوب (~145 MB أو أكثر بسبب تمثيل الرسم).
- التوليد يعيد حساب السياق لكل رمز في هذه النسخة؛ لا يحتوي KV cache. زمن الاستجابة واستهلاك الذاكرة على Galaxy A16 يحتاجان قياسًا فعليًا؛ لا يوجد ادعاء بسرعة محددة.
- الاستيراد يدعم ملف ONNX مستقلًا واحدًا حتى 300 MiB وبعقد `musab-v12-full-v1`؛ لا يدعم ملفات بيانات ONNX الخارجية.
- حد السؤال 192 رمز بايت شامل قالب السؤال؛ الجواب 64 رمزًا. الإيقاف يُفحص بين عمليات الاستدلال، وقد ينتظر اكتمال عملية الرمز الحالية.
- لا توجد آلة حاسبة بديلة أو أجوبة مصطنعة عند غياب الأوزان. يجب استيراد النموذج أولًا.
- إعادة تعيين تحذف نسخة التطبيق فقط؛ لا تحذف ملف الأوزان الذي اخترته من الهاتف.

## التحقق والبناء

المطلوب JDK 17 وAndroid SDK 35 وGradle 8.11.1:

```bash
gradle testDebugUnitTest lintDebug assembleDebug
python tools/test_export.py
```

CI يفحص تطابق التحويل على نموذج صغير بنفس العمليات، وليس دقة الأوزان المدرّبة. أداة التصدير تعيد الفحص على أوزان المستخدم عند التحويل. اختبار الجهاز الحقيقي ما زال مطلوبًا: استيراد، حل، إيقاف، إعادة فتح التطبيق، رفض ملف خاطئ، إعادة تعيين.

المراجع: [ONNX Runtime Java](https://onnxruntime.ai/docs/get-started/with-java.html)، [ONNX Mobile](https://onnxruntime.ai/docs/get-started/with-mobile.html)، [AGP 8.9](https://developer.android.com/build/releases/agp-8-9-0-release-notes).
